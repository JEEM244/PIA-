# Dónde colocar las imágenes de FORJA

Todas las imágenes de la página se guardan dentro de esta carpeta.

## Imagen principal de la portada
Coloca tu imagen aquí:

`assets/img/portada.jpg`

La página la muestra como fondo semitransparente detrás del título.

## Fotografías de los productos
Coloca una fotografía por artículo dentro de:

`assets/img/productos/`

El nombre del archivo debe coincidir con el nombre del artículo de la base de datos, convertido a minúsculas, sin acentos y con guiones.

Ejemplos:
- Artículo "Martillo de acero" → `martillo-de-acero.jpg`
- Artículo "Cable eléctrico" → `cable-electrico.jpg`
- Artículo "Taladro 1/2" → `taladro-1-2.jpg`

Si todavía no existe la fotografía, la tarjeta mostrará "Imagen pendiente". En cuanto agregues el archivo JPG con el nombre correcto, aparecerá automáticamente.

## Recomendaciones
- Usa formato JPG.
- Para productos, procura imágenes cuadradas o casi cuadradas.
- Para la portada, usa una imagen horizontal.
- No necesitas modificar PHP ni CSS para agregar fotografías.
